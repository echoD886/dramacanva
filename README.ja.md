# DramaCanvas

**AI 映像制作、ショートドラマ、ビジュアルストーリーテリングのためのオープンソース・フロントエンド。**

[オンラインで試す](https://dramacanva.com/) · [API 連携](docs/api.md) · [公開範囲](docs/scope.md)

[English](README.md) · [简体中文](README.zh-CN.md) · [Français](README.fr.md) · 日本語

![DramaCanvas — 物語を映像へ](docs/assets/cover.png)

DramaCanvas は、物語の企画、無限キャンバス、再利用できる制作スキルを一つのワークスペースにまとめたツールです。このリポジトリでは、製品の一部のページとコンポーネントを公開しています。実装の学習、独自の制作ツールの開発、自分のバックエンドとの連携に活用できます。

**これはフロントエンドのプレビュー版であり、オンラインサービス全体ではありません。** ローカル版は隔離されたデモデータを使用します。実際の AI 生成、クラウドアカウント、決済、サーバーストレージは含まれません。製品全体は [dramacanva.com](https://dramacanva.com/) でお試しください。

## DramaCanvas でできること

[dramacanva.com](https://dramacanva.com/) では、物語や脚本をもとにショートドラマのプロジェクトを作成し、登場人物や絵コンテのカットを計画できます。AI モデルで画像や動画クリップを生成し、無限キャンバスで制作素材を整理することもできます。制作スキルや動画テンプレートを活用して、ショートドラマ、短編映画、ミュージックビデオなどの制作手順を再利用できます。利用できる生成オプションは、モデルとアカウントによって異なります。

**[オンラインの制作ワークスペースを開く →](https://dramacanva.com/)**

## ローカルで起動する

Node.js 22.12 以降と Bun 1.3 以降が必要です。

```bash
git clone https://github.com/echoD886/dramacanva.git
cd dramacanva
bun install
bun run dev
```

**http://127.0.0.1:5173** を開いてください。アカウント、API キー、バックエンドの設定は不要です。

```bash
bun run build
bun run preview
bun run typecheck
bun run test
bun run audit:public
```

ビルド後のプレビューは **http://127.0.0.1:4173** で表示されます。サーバーが必要な操作は、その旨を示すエラーを返します。生成が成功したように装うことはありません。

## 独自のバックエンドとの連携

フロントエンドで使うリクエストとレスポンスの TypeScript 型を含めています。[API 連携ガイド](docs/api.md)では、プロジェクト、スキル、テンプレート、生成タスクの入力と、デモ用通信層の置き換え箇所を説明しています。

モデル提供元のキーはサーバー側で管理してください。認証、権限管理、保存、タスク実行は別途実装が必要です。この公開版は DramaCanvas のオンライン API に接続しません。

## 多言語と SEO

標準言語は英語です。README は中国語、フランス語、日本語でも提供しています。既存の公開コンテンツは英語、簡体字・繁体字中国語、日本語、韓国語、スペイン語、ポルトガル語に対応していますが、対応範囲はページによって異なります。フランス語の README があることは、アプリ全体のフランス語対応を意味しません。

タイトル、説明、canonical、言語別 URL、スキル紹介・FAQ・手順の構造化データを扱う補助コードを含めています。ローカルプレビューは **noindex** です。オンライン版のプリレンダリング、サイトマップ送信、アクセス解析は含まれません。公開前に [SEO の説明](docs/seo.md)を確認してください。

## ディレクトリ構成

ページは `src/pages/`、共通コンポーネントは `src/components/`、公開コンテンツは `src/content/`、翻訳は `src/i18n/` にあります。`src/services/api/` に API の型とクライアント、`src/demo/` に隔離されたデモデータを配置しています。`public/` はロゴと代替画像、`docs/` は連携と SEO の説明です。

技術スタック：React、TypeScript、Vite、Ant Design、Tailwind CSS、Zustand。
